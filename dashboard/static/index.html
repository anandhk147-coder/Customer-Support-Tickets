Multi-Product Customer (Asha Rao) Customer Product
Target Cypher Query (Find Customers with Tickets for >1 Product) Exact assignment requirement 
MATCH (c:Customer)-[:RAISED]->(t:Ticket)-[:ABOUT]->(p:Product)
WITH c, 
     count(DISTINCT p) AS distinct_products_count, 
     collect(DISTINCT p.name) AS products,
     collect(t.ticket_id) AS tickets_raised
WHERE distinct_products_count > 1
RETURN c.name AS customer_name, distinct_products_count, products, tickets_raised
ORDER BY distinct_products_count DESC, customer_name ASC;
